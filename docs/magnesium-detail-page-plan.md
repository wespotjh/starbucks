# 마그네슘 상세페이지 기획안 (v2 — 웰니스 루틴 컨셉)

- 작성일: 2026-08-21
- 핵심 키워드: **숙면**, **리커버리**
- 포지셔닝: 증상 해결용 영양제 ❌ → **비타민C처럼 매일 챙기는 데일리 웰니스 미네랄** ⭕
- 목표: "나 이거 왜 안 먹고 있었지?"라는 인식 전환 → 루틴템으로 첫 구매 + 정기 재구매

---

## 1. 기획 방향 요약

v1의 결핍·증상 저격형(쥐, 눈떨림, 새벽 각성)은 폐기한다.
아픈 사람을 찾아가는 페이지가 아니라, **잘 살고 싶은 사람의 루틴에 들어가는 페이지**로 만든다.

### 핵심 포지셔닝 한 줄

> **"비타민C가 아침의 습관이라면, 마그네슘은 밤의 습관입니다."**

- 비타민C를 챙겨 먹는 데 이유가 필요 없듯, 마그네슘도 "기본으로 챙기는 것"이라는 프레임을 심는다
- 그 기본템이 주는 보상이 바로 **숙면**(오늘 밤)과 **리커버리**(내일 아침)다
- 톤: 치료·개선이 아니라 **관리·리추얼**. "고친다"가 아니라 "챙긴다"

### 두 키워드의 역할
| 키워드 | 프레임 | 카피 방향 |
|--------|--------|----------|
| 숙면 | 하루를 잘 닫는 나이트 루틴 | "하루의 마무리", "밤의 컨디션 관리" |
| 리커버리 | 내일을 여는 컨디션 관리 | "내일의 나를 위한 준비", "쉼도 실력" |

## 2. 타겟 페르소나

### 페르소나 A — "루틴을 가꾸는 2030" (메인)
- 미라클모닝은 못 해도 나이트 루틴엔 진심: 스트레칭, 반신욕, 캔들, 수면 앱
- 유산균·비타민C·오메가3는 이미 먹는 중 → 영양제 소비에 거부감 없음
- 관심사: 갓생, 이너케어, 웰니스, 슬로우라이프
- 검색어: `나이트루틴 영양제`, `마그네슘 추천`, `데일리 영양제 조합`
- 심리: "결핍이라서"가 아니라 "나를 잘 관리하는 사람이라서" 먹고 싶다

### 페르소나 B — "운동이 일상인 사람" (서브)
- 러닝·헬스·요가가 루틴의 일부. 프로틴 챙기듯 회복도 루틴으로 관리하고 싶음
- 리커버리를 "부상 치료"가 아니라 **퍼포먼스 관리**로 인식
- 검색어: `운동 루틴 영양제`, `리커버리 루틴`, `컨디션 관리`

### 공통 인사이트
이들에게 팔리는 건 "효능"이 아니라 **"이걸 챙기는 나"라는 정체성**이다.
→ 페이지 전체가 "결핍 보충"이 아니라 "라이프스타일 완성"의 문법으로 말해야 한다.

## 3. 핵심 메시지 구조

| 구분 | 내용 |
|------|------|
| 원 메시지 | 비타민C처럼, 마그네슘도 매일. 잘 쉬는 것까지가 오늘의 루틴이니까 |
| 숙면 축 약속 | 하루를 편안하게 닫는 밤의 미네랄 |
| 리커버리 축 약속 | 열심히 산 몸을 위한 데일리 리커버리 |
| 신뢰 근거 | 식약처 인정 기능성 원료, 흡수 형태(제형), 함량, 인증/검사 성적서 |

### 식약처 인정 기능성 (표현의 한계선)
마그네슘의 공식 인정 기능성은 아래 2가지. 모든 카피는 이 범위 안에서 논다.
1. **에너지 이용에 필요**
2. **신경과 근육 기능 유지에 필요**

→ 웰니스 컨셉은 오히려 심의에 유리하다. "숙면을 유도한다" 같은 효능 단정 대신
"밤의 루틴", "리커버리 타임" 같은 **라이프스타일 언어**를 쓰는 것이 컨셉 자체이기 때문.

## 4. 페이지 스토리보드 (섹션 구성)

전체 흐름: **무드 공감(라이프스타일) → 인식 전환(왜 기본템인가) → 루틴 제안 → 제품 디테일 → 신뢰 → 행동**
v1의 "문제 → 원인 → 해결" 구조를 버리고, 잡지 화보 같은 **루틴 제안 구조**로 간다.

### SEC 01. 후킹 (인트로 비주얼)
- 화면: 어두운 문제 상황 ❌ → 따뜻한 조명의 저녁, 차를 내리듯 영양제 한 알을 꺼내는 손, 정돈된 침구
- 헤드 카피 시안:
  - A안: **"비타민C가 아침이라면, 마그네슘은 밤입니다"** — 포지셔닝 그 자체. 메인 추천
  - B안: **"하루를 잘 닫는 사람이, 내일을 잘 엽니다"** — 숙면→리커버리 서사 압축
  - C안: **"잘 쉬는 것도 루틴입니다"** — 운동/갓생 트래픽용
- 서브 카피: "신경과 근육 기능 유지에 필요한 미네랄, 마그네슘. 오늘 밤부터 루틴에 더하세요"

### SEC 02. 라이프스타일 공감 (증상 체크 ❌ → 루틴 공감 ⭕)
- "이미 잘 챙기고 계시죠?" — 아침 비타민C, 점심 유산균, 운동 후 프로틴… 아이콘 타임라인으로 나열
- 반전 카피: **"그런데 하루의 3분의 1, 밤은 무엇으로 챙기고 있나요?"**
- 의도: 결핍을 지적하지 않고 **루틴의 빈칸**을 보여준다. 이미 영양제를 먹는 사람일수록 강하게 걸리는 훅.

### SEC 03. 인식 전환 (마그네슘 = 기본템)
- 내용: 마그네슘은 체내 300여 가지 효소 반응에 관여하는 필수 미네랄 / 커피·스트레스·운동(땀)이 일상인 현대인일수록 매일 채워야 함 / 한국인 평균 섭취 부족 통계(국민건강영양조사 — **출처 명시**)
- 카피: "열심히 사는 하루가 쓰는 미네랄. 그래서 열심히 사는 사람일수록, 매일 채워야 합니다"
- 톤 주의: "부족하면 큰일난다" 공포 소구 ❌ → "쓰는 만큼 채우는 게 관리다" 담백한 논리 ⭕

### SEC 04. 제품 등장
- 무드: 약병 느낌 ❌ → 화장대·침대 협탁 위에 자연스럽게 놓인 라이프스타일 컷 (이너케어 감성)
- 카피: "밤의 루틴에 한 알을 더했습니다"
- 기능성 문구 고정 노출: "정상적인 신경과 근육 기능 유지에 필요 / 에너지 이용에 필요"

### SEC 05. 나이트 루틴 제안 (숙면 축 — 페이지의 심장)
- 타임라인 그래픽: 밤 10시 스마트폰을 내려놓고 → 미지근한 물 한 잔과 마그네슘 한 알 → 스트레칭 → 취침
- 카피: **"오늘 밤부터 따라 해보세요, 마그네슘 나이트 루틴"**
- 의도: 제품을 파는 게 아니라 **루틴을 파는 섹션**. 저장·공유하고 싶은 콘텐츠형 구성(SNS 소재로 재활용).

### SEC 06. 데일리 리커버리 (리커버리 축)
- 장면: 아침 창가 스트레칭, 러닝 후 세이지색 매트 위의 휴식 — "회복하는 장면"을 아름답게
- 카피: "운동한 날도, 야근한 날도. 몸을 많이 쓴 날일수록 밤의 한 알이 다음 날을 만듭니다"
- 서브: "쉼도 실력입니다. 리커버리까지가 오늘의 운동"
- 의도: 리커버리를 통증 케어가 아니라 **퍼포먼스·컨디션 관리**로 프레이밍.

### SEC 07. 차별점 ① 흡수 형태 (제형 스토리)
- 산화마그네슘 vs 유기산염/킬레이트형(글리시네이트·구연산 등) 비교표
- 카피: "매일 먹는 것이라서, 형태부터 골랐습니다"
- 톤 주의: "싼 건 속 버린다" 식 공포 비교 ❌ → "데일리로 먹기 좋은 형태 기준" ⭕
- ※ 실제 원료 형태·근거 자료 확보 후 수치 기입

### SEC 08. 차별점 ② 함량 & 설계
- 1일 섭취량당 함량 + 영양성분기준치 % / 부원료(비타민B6, 테아닌 등 실제 배합 기준, 각자 인정 기능성 범위 내 서술)
- 카피: "매일 부담 없이, 그러나 하루치는 확실하게"
- 알약 크기·향·목넘김 등 **데일리템의 디테일** 강조 (매일 먹는 것의 구매 결정 요인)

### SEC 09. 사회적 증거
- 리뷰 큐레이션 기준 변경: "루틴이 됐다", "떨어지면 불안해서 재구매" 류의 **습관·재구매 서사** 우선
- 재구매율·정기구독 수치가 있다면 이 컨셉의 최강 증거 → 최상단 배치
- 데이터 없을 시: 개발 스토리("우리가 매일 먹으려고 만든") + 체험단 루틴 후기

### SEC 10. 신뢰 · 안전성
- 인증 아이콘 존: 건강기능식품 인증마크, GMP, 중금속 검사 성적서, 무첨가 배지
- 카피: "비타민C처럼 매일 먹는 것이니까, 더 까다롭게 만들었습니다" — 포지셔닝 문장을 신뢰 근거로 재사용

### SEC 11. 섭취 방법 & FAQ
- 언제: 저녁, 하루를 마무리할 때 1알 (나이트 루틴 연결)
- FAQ:
  1. 언제 먹는 게 가장 좋나요? → 밤 루틴 제안 (아침도 무방)
  2. 비타민C·유산균이랑 같이 먹어도 되나요? → **"기존 루틴에 그대로 더하세요"** (포지셔닝 강화 답변)
  3. 매일 먹어도 되나요? → 데일리 섭취 설계 강조 + 과다 섭취 주의 의무 표기
  4. 커피 마시는데 괜찮나요? → 시간차 섭취 팁
  5. 임산부/신장질환자 → 전문가 상담 안내
- 주의사항 정직하게 표기 (신뢰 신호)

### SEC 12. 클로징 CTA
- 카피: **"내일의 컨디션은, 오늘 밤에 만들어집니다"**
- CTA 버튼: **"오늘 밤 루틴에 추가하기"** (보조: "정기구독으로 ○% 할인")
- 구성: 1개월 체험 / 3개월 루틴팩(추천 배지) / **정기구독** — 루틴 포지셔닝이므로 구독 옵션이 컨셉과 정합. 구독 넛지 카피: "루틴은 끊기지 않을 때 루틴이 됩니다"

## 5. 카피라이팅 원칙 (v2 전용)

1. **결핍의 언어 금지**: 부족, 결핍, 증상, 완화, 개선 → 챙기다, 채우다, 더하다, 관리하다, 루틴
2. **비타민C 앵커링**: 페이지에서 최소 2회(인트로, 신뢰 섹션) "비타민C처럼"을 반복해 기본템 프레임 각인
3. 효능 단정 대신 장면: "숙면에 좋다" ❌ → 밤 루틴의 장면 묘사 ⭕
4. 키워드 배치: 숙면 = SEC 05 나이트 루틴에서, 리커버리 = SEC 06에서 각각 라이프스타일 언어로 소화
5. 느낌표 금지, 명령 대신 제안형("~해보세요")
6. 모바일 우선: 1스크린 1메시지, 카피 2줄 이내

## 8. ⚠️ 표시·광고 심의 체크리스트 (필수)

건강기능식품 표시·광고는 자율심의(한국건강기능식품협회) 사전 심의 대상.

| 구분 | 금지 | 대안 |
|------|------|------|
| 질병 표현 | "불면증", "수면장애" 등 질병명 | 질병명 자체를 쓰지 않는다 |
| 기능성 초과 | "숙면 유도", "꿀잠", "회복 촉진", "근육통 완화" | 인정 문구 + 루틴/라이프스타일 묘사 |
| 단정/보장 | "2주면 달라집니다", "100% 체감" | 기간·확률 단정 전면 금지 |
| 비교 비방 | 특정사·특정 제품 비방 | 일반적 형태(산화 vs 킬레이트) 비교까지만 |
| 후기 | 효능 체감 후기 그대로 인용 | 심의 범위 내 표현의 후기만 선별 |

웰니스 컨셉의 이점: "루틴", "챙기다", "컨디션 관리"는 효능 주장이 아니라서 심의 리스크가 낮다.
단, **"리커버리"를 회복 효능으로 읽히게 쓰면 안 되고** 라이프스타일 용어(리커버리 타임, 리커버리 루틴)로만 사용한다. 최종 문구는 심의 결과에 따라 조정.
