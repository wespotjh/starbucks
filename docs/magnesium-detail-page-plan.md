# 마그네슘 상세페이지 기획안

- 작성일: 2026-08-21
- 핵심 키워드: **숙면**, **리커버리**
- 목표: 상세페이지 스크롤 완주율을 높이고, 구매 전환(장바구니/구매하기 클릭)으로 연결

---

## 1. 기획 방향 요약

마그네슘은 "미네랄 보충제"로 팔면 지루하고, 경쟁 제품과 차별화가 안 된다.
이 페이지는 성분이 아니라 **"오늘 밤"과 "내일 아침"** 을 판다.

- **숙면 축**: 잠들기까지 오래 걸리고, 자다 깨는 사람 → "밤이 편해진다"
- **리커버리 축**: 운동 후 뻐근함, 다리 저림/쥐, 아침 피로 → "다음 날이 가벼워진다"

두 키워드는 별개가 아니라 하나의 스토리로 연결한다:
**"잘 자야, 회복된다. 회복돼야, 내일이 달라진다."**

## 2. 타겟 페르소나

### 페르소나 A — "잠이 얕은 30대 직장인" (숙면 축)
- 침대에 누워도 30분 이상 뒤척임, 새벽에 1~2번 깸
- 커피를 줄여봐도 그대로, 수면 영양제는 뭔가 세 보여서 부담
- 검색어: `잠 잘오는 영양제`, `마그네슘 수면`, `자다 깨는 이유`
- 심리적 장벽: "영양제 하나로 잠이 달라진다고? 과장 아니야?"

### 페르소나 B — "주 3회 운동하는 2030" (리커버리 축)
- 헬스/러닝/클라이밍 후 근육이 뭉치고, 자다가 종아리 쥐가 남
- 단백질은 챙기는데 미네랄은 신경 못 씀
- 검색어: `운동 후 회복 영양제`, `근육 경련 마그네슘`, `다리 쥐 영양제`
- 심리적 장벽: "마그네슘 다 똑같은 거 아니야? 제일 싼 거 사면 되지"

### 공통 인사이트
둘 다 "문제는 알지만 마그네슘이 답인 줄 모르는" 상태.
→ 상세페이지 초반부는 제품 자랑이 아니라 **문제-원인 연결(교육)** 에 써야 한다.

## 3. 핵심 메시지 구조

| 구분 | 내용 |
|------|------|
| 원 메시지 | 뒤척이는 밤과 뻐근한 아침, 부족한 건 의지가 아니라 마그네슘일 수 있습니다 |
| 숙면 축 약속 | 예민해진 신경을 편안하게 → 눕는 시간이 편해진다 |
| 리커버리 축 약속 | 뭉친 근육의 정상 기능 유지 → 다음 날 몸이 가볍다 |
| 신뢰 근거 | 식약처 인정 기능성 원료, 흡수 형태(제형), 함량, 부원료, 인증/검사 성적서 |

### 식약처 인정 기능성 (표현의 한계선)
마그네슘의 공식 인정 기능성은 아래 2가지뿐이다. 모든 카피는 이 표현을 벗어나면 안 된다.
1. **에너지 이용에 필요**
2. **신경과 근육 기능 유지에 필요**

→ "숙면"과 "리커버리"는 **직접 효능이 아니라 라이프스타일 맥락(상황 묘사)** 으로 풀어야 한다. (상세 규정은 8번 항목)

## 4. 페이지 스토리보드 (섹션 구성)

전체 흐름: **공감(문제) → 교육(원인) → 해결(제품) → 증명(신뢰) → 안심(FAQ) → 행동(CTA)**

### SEC 01. 후킹 (인트로 비주얼)
- 화면: 어두운 침실, 뒤척이는 사람 실루엣 → 밝은 아침으로 전환되는 무드
- 헤드 카피 시안:
  - A안: **"눕자마자 잠들고, 개운하게 일어나는 사람들의 미네랄"** — 결과 상태를 그림
  - B안: **"오늘도 3시에 깼다면, 읽어보세요"** — 문제 저격형, 스크롤 유도력 높음
  - C안: **"운동은 열심히, 회복은 대충?"** — 리커버리 트래픽용 (광고 소재별 스왑 가능)
- 서브 카피: "신경과 근육 기능 유지에 필요한 마그네슘, 하루 1알로 챙기세요"

### SEC 02. 문제 공감 (체크리스트)
- "혹시 이런 적 있나요?" 체크리스트 6개:
  - ☑ 누워도 30분 넘게 뒤척인다
  - ☑ 자다가 한두 번은 꼭 깬다
  - ☑ 아침에 일어나도 잔 것 같지 않다
  - ☑ 운동 다음 날 유독 뻐근하다
  - ☑ 자다가 다리에 쥐가 난 적이 있다
  - ☑ 눈 밑이 파르르 떨린 적이 있다
- 마무리 카피: "3개 이상 해당된다면, 마그네슘이 부족하다는 신호일 수 있습니다"
- 의도: 숙면 3개 + 리커버리 3개로 두 키워드 모두 커버. 자가진단은 체류시간·공감도를 높이는 검증된 장치.

### SEC 03. 원인 교육 (왜 마그네슘인가)
- 내용: 마그네슘은 체내 300여 가지 효소 반응에 관여하는 필수 미네랄 / 커피·스트레스·땀으로 배출 / 한국인 평균 섭취량이 권장량에 못 미친다는 통계(국민건강영양조사 등 **출처 명시 필수**)
- 카피: "커피 한 잔, 야근, 오늘의 운동. 당신이 열심히 살수록 마그네슘은 더 빨리 사라집니다"
- 인포그래픽: 마그네슘이 빠져나가는 3가지 경로 (카페인 / 스트레스 / 땀)

### SEC 04. 솔루션 제시 (제품 등장)
- 첫 제품 컷. 패키지 + 알약 실물 크기 비교(손 위 컷 — 삼키기 부담 없다는 신호)
- 카피: "그래서 만들었습니다. 밤과 아침을 위한 마그네슘"
- 기능성 문구 고정 노출: "정상적인 신경과 근육 기능 유지에 필요 / 에너지 이용에 필요"

### SEC 05. 차별점 ① 흡수 형태 (제형 스토리)
- 산화마그네슘(값싸고 흡수율 낮음, 속쓰림 이슈) vs 유기산염/킬레이트형(글리시네이트·구연산 등) 비교표
- 카피: "마그네슘, 얼마나 먹느냐보다 **어떤 형태로 먹느냐** 가 중요합니다"
- 의도: 페르소나 B의 "다 똑같은 거 아니야?" 장벽을 정면으로 깨는 섹션. 최저가 경쟁에서 빠져나오는 핵심 논리.
- ※ 실제 원료 형태·흡수율 근거 자료는 제조사에서 확보 후 수치 기입 (미확보 시 비교표에서 수치 삭제)

### SEC 06. 차별점 ② 함량 & 부원료 설계
- 1일 섭취량당 마그네슘 함량 + 영양성분기준치 % 명시
- 시너지 부원료(예: 비타민B6, 테아닌 등 실제 배합 기준) 소개 — 각 부원료도 인정받은 기능성 범위 내에서만 서술
- 표현 형식: "숙면 루틴을 위한 저녁 1알" (루틴 제안 = 상황 묘사, 효능 단정 아님)

### SEC 07. 데일리 루틴 제안 (키워드 2축 통합)
- 타임라인 그래픽: **밤 10시 — 1알과 함께 하루를 정리 → 밤 — 편안한 신경 → 아침 — 가벼운 몸으로 리커버리 완료**
- 카피: "잘 자는 것이 최고의 리커버리입니다"
- 의도: 숙면과 리커버리를 하나의 서사로 묶는 페이지의 중심 섹션.

### SEC 08. 사회적 증거
- 실구매 리뷰 캡처(동의받은 것만) / 누적 판매량 / 재구매율 등 **실데이터만** 사용
- 리뷰 큐레이션 기준: "잠" 관련 2개 + "운동/회복" 관련 2개로 균형
- 데이터 없을 시(신제품): 출시 기념 체험단 후기, 개발 스토리로 대체

### SEC 09. 신뢰 · 안전성
- 인증 아이콘 존: 건강기능식품 인증마크, GMP, 중금속/잔류농약 검사 성적서, 무첨가(합성착향료 등) 배지
- 카피: "매일 먹는 것이니까, 까다롭게 만들었습니다"

### SEC 10. 섭취 방법 & 주의사항
- 언제: 저녁 식후 1알 (숙면 루틴 연결)
- 주의: 신장 질환자 상담 권고, 과다 섭취 시 설사 가능 등 의무 표기
- 의도: 주의사항을 숨기지 않는 것 자체가 신뢰 신호

### SEC 11. FAQ (구매 직전 장벽 제거)
1. 언제 먹는 게 좋나요? → 저녁 루틴 제안
2. 얼마나 먹어야 하나요? → 꾸준함 강조 (단, "○주 후 효과" 같은 기간 단정 금지)
3. 다른 영양제와 같이 먹어도 되나요? → 칼슘과의 관계 등
4. 속이 불편하지 않을까요? → 제형 스토리 재소환
5. 임산부/청소년도 먹을 수 있나요? → 전문가 상담 안내

### SEC 12. 클로징 CTA
- 카피: "오늘 밤부터 달라지는 건 아니어도, 오늘 밤부터 챙길 수는 있습니다" — 과장 없이 진정성으로 마무리
- CTA 버튼: **"내 밤과 아침 챙기기"** (보조: "첫 구매 ○% 할인받고 시작하기")
- 구성: 가격/구성(1개월·3개월) 옵션 비교 + 3개월 구성 추천 배지

## 5. 카피라이팅 원칙 (이 페이지 전용)

1. 효능을 말하지 말고 **장면을 그린다**: "숙면에 좋다" ❌ → "눕는 시간이 편해집니다" 컨셉의 상황 묘사 ⭕
2. 숫자는 출처와 함께: 함량, 흡수율, 통계 모두 각주 처리
3. 느낌표 금지, 단정 대신 제안: "~하세요!" ❌ → "~해보세요" ⭕
4. 두 키워드의 밸런스: 스크롤 상단 = 숙면 우세, 중반 = 리커버리 합류, 하단 = 통합 서사
5. 모바일 우선: 한 화면(세로 1스크린)에 메시지 1개, 카피는 2줄 이내

## 6. 디자인 톤앤매너

| 요소 | 방향 |
|------|------|
| 무드 | 상단: 딥 네이비 + 라벤더 (밤, 숙면) → 하단으로 갈수록 소프트 아이보리 + 세이지 (아침, 회복) |
| 그라데이션 서사 | 페이지 스크롤 자체가 "밤 → 아침"이 되도록 배경 톤 전환 |
| 폰트 | 제목: 고딕 계열 볼드 / 본문: 가독성 높은 산세리프, 모바일 기준 최소 28px(상세이미지 기준) |
| 사진 | 침실·아침 스트레칭·운동 후 장면 등 라이프스타일 컷 위주, 알약 확대컷은 신뢰 섹션에만 |
| 규격 | 가로 860px, 섹션당 세로 1000~1500px, 총 12섹션 (스마트스토어/자사몰 겸용) |

## 8. ⚠️ 표시·광고 심의 체크리스트 (필수)

건강기능식품 표시·광고는 **자율심의(한국건강기능식품협회) 사전 심의 대상**이다. 아래를 어기면 심의 반려 또는 행정처분 리스크.

| 구분 | 금지 | 대안 |
|------|------|------|
| 질병 표현 | "불면증 개선", "수면장애에 효과" | 질병명 자체를 쓰지 않는다 |
| 기능성 초과 | "숙면 유도", "꿀잠 보장", "근육통 완화" | 인정 문구("신경과 근육 기능 유지에 필요") + 상황 묘사 |
| 단정/보장 | "2주면 달라집니다", "100% 체감" | 기간·확률 단정 전면 금지 |
| 비교 비방 | "타사 산화마그네슘은 쓰레기" | 일반적 형태 비교는 가능하되 특정사 비방 금지 |
| 후기 | 효능 체감 후기를 광고에 그대로 인용 | 심의받은 표현 범위 내 후기만 선별 |

**진행 순서**: 시안 완성 → 내부 검수(이 표 기준) → 협회 심의 접수 → 심의필 획득 후 게시.
"숙면", "리커버리"는 **광고 소재·검색 키워드 전략 차원의 컨셉 워드**로 쓰되, 상세페이지 본문에서는 심의 통과 가능한 상황 묘사로 변환하는 것이 이 기획의 핵심 기술이다. 최종 문구는 심의 결과에 따라 조정한다.
