# 마그네슘 상세페이지 기획안 (v2.1 — 웰니스 루틴 · 파우더 · 모바일 전용)

- 작성일: 2026-08-23
- 핵심 키워드: **숙면**, **리커버리**
- 제품 형태: **파우더(가루) — 물에 타서 마시는 타입** (알약 아님)
- 판매 환경: **모바일 열람·구매가 사실상 100% → 모든 콘텐츠·이미지 세로 1열 배치, 가로 그리드 금지**
- 포지셔닝: 증상 해결용 영양제 ❌ → **비타민C처럼 매일 챙기는 데일리 웰니스 미네랄** ⭕
- 목표: "나 이거 왜 안 먹고 있었지?"라는 인식 전환 → 루틴템으로 첫 구매 + 정기 재구매

## 1. 기획 방향 요약

결핍·증상 저격형(쥐, 눈떨림, 새벽 각성)은 쓰지 않는다.
아픈 사람을 찾아가는 페이지가 아니라, **잘 살고 싶은 사람의 루틴에 들어가는 페이지**로 만든다.

### 오프닝 컨셉

> **"웰니스 필수 미네랄, 마그네슘"**

- 첫 화면은 카테고리 선언형으로 연다 — 설득이 아니라 "당연히 챙기는 것"이라는 프레임 선점
- "비타민C처럼"이라는 앵커링은 오프닝 헤드라인이 아니라 **본문(SEC 02 루틴의 빈칸, SEC 10 신뢰 카피)에서만** 사용한다
- 그 기본템이 주는 보상이 **숙면**(오늘 밤)과 **리커버리**(내일 아침)
- 톤: 치료·개선이 아니라 **관리·리추얼**. "고친다"가 아니라 "챙긴다"

### 파우더라는 무기

알약이 아니라 물에 타서 마시는 가루라는 점은 약점이 아니라 이 페이지의 핵심 차별점이다:
- **"마시는 마그네슘"** — 저녁에 따뜻한 물 한 잔에 타서 마시는 행위 자체가 나이트 루틴이 된다 (차 우리는 리추얼과 같은 문법)
- 알약 목넘김이 부담스러운 사람에게 진입 장벽 제거
- 숙면 컨셉과 "마시는 한 잔"의 결합은 알약 제품이 흉내 낼 수 없는 서사

### 두 키워드의 역할
| 키워드 | 프레임 | 카피 방향 |
|--------|--------|----------|
| 숙면 | 하루를 잘 닫는 나이트 루틴 | "하루의 마무리", "밤의 한 잔" |
| 리커버리 | 내일을 여는 컨디션 관리 | "내일의 나를 위한 준비", "쉼도 실력" |

## 2. 타겟 페르소나

### 페르소나 A — "루틴을 가꾸는 2030" (메인)
- 나이트 루틴에 진심: 스트레칭, 반신욕, 캔들, 수면 앱, 자기 전 차 한 잔
- 유산균·비타민C·오메가3는 이미 먹는 중 → 영양제 소비에 거부감 없음
- 관심사: 갓생, 이너케어, 웰니스, 슬로우라이프
- 검색어: `나이트루틴 영양제`, `마그네슘 추천`, `마시는 마그네슘`, `마그네슘 가루`
- 심리: "결핍이라서"가 아니라 "나를 잘 관리하는 사람이라서" 먹고 싶다

### 페르소나 B — "운동이 일상인 사람" (서브)
- 러닝·헬스·요가가 루틴의 일부. 프로틴 셰이크처럼 회복도 "타서 마시는" 문법에 익숙
- 리커버리를 "부상 치료"가 아니라 **퍼포먼스 관리**로 인식
- 검색어: `운동 루틴 영양제`, `리커버리 루틴`, `컨디션 관리`

### 공통 인사이트
이들에게 팔리는 건 "효능"이 아니라 **"이걸 챙기는 나"라는 정체성**이다.
→ 페이지 전체가 "결핍 보충"이 아니라 "라이프스타일 완성"의 문법으로 말해야 한다.

## 3. 핵심 메시지 구조

| 구분 | 내용 |
|------|------|
| 원 메시지 | 웰니스 필수 미네랄, 마그네슘. 잘 쉬는 것까지가 오늘의 루틴이니까 |
| 숙면 축 약속 | 하루를 편안하게 닫는 밤의 한 잔 |
| 리커버리 축 약속 | 열심히 산 몸을 위한 데일리 리커버리 |
| 신뢰 근거 | 식약처 인정 기능성 원료, 원료 형태, 함량, 인증/검사 성적서 |

### 식약처 인정 기능성 (표현의 한계선)
마그네슘의 공식 인정 기능성은 아래 2가지. 모든 카피는 이 범위 안에서 논다.
1. **에너지 이용에 필요**
2. **신경과 근육 기능 유지에 필요**

→ "숙면을 유도한다" 같은 효능 단정 대신 "밤의 루틴", "리커버리 타임" 같은
**라이프스타일 언어**를 쓰는 것이 컨셉 자체라서, 웰니스 컨셉은 심의에도 유리하다.

## 4. 페이지 스토리보드 (섹션 구성)

전체 흐름: **무드 공감(라이프스타일) → 인식 전환(왜 기본템인가) → 루틴 제안 → 제품 디테일 → 신뢰 → 행동**

**모바일 레이아웃 원칙 (전 섹션 공통)**
- 아이콘 나열, 카드 비교, 옵션 선택 등 모든 요소는 **세로 1열 스택**으로 배치한다 (가로 그리드·가로 스크롤 금지)
- 1스크린 1메시지, 카피 2줄 이내, 이미지 사이 여백으로 호흡

### SEC 01. 후킹 (인트로 비주얼)
- 화면: 따뜻한 조명의 저녁, 유리잔에 파우더를 타는 손, 정돈된 침구
- 헤드 카피 시안:
  - A안: **"웰니스 필수 미네랄, 마그네슘"** — 카테고리 선언형. 메인 추천
  - B안: **"하루를 잘 닫는 사람이, 내일을 잘 엽니다"** — 숙면→리커버리 서사 압축
  - C안: **"잘 쉬는 것도 루틴입니다"** — 운동/갓생 트래픽용
- 서브 카피: "물에 타서 마시는 데일리 미네랄 — 신경과 근육 기능 유지에 필요한 마그네슘"

### SEC 02. 라이프스타일 공감 (루틴의 빈칸)
- "이미 잘 챙기고 계시죠?" — 아침 비타민C → 점심 유산균 → 운동 후 프로틴, **세로 타임라인**으로 나열
- 마지막 칸을 비워둔다: "밤 · ?"
- 반전 카피: **"그런데 하루의 3분의 1, 밤은 무엇으로 챙기고 있나요?"**
- 의도: 결핍을 지적하지 않고 루틴의 빈칸을 보여준다. 비타민C 앵커링은 여기서 자연스럽게 발생.

### SEC 03. 인식 전환 (마그네슘 = 기본템)
- 내용: 체내 300여 가지 효소 반응에 관여하는 필수 미네랄 / 커피·스트레스·운동(땀)이 일상인 현대인일수록 매일 채워야 함 / 한국인 평균 섭취 부족 통계(국민건강영양조사 — **출처 명시**)
- 소모 경로 3가지(커피/스트레스/땀)도 세로 카드 스택으로
- 카피: "열심히 사는 하루가 쓰는 미네랄. 그래서 열심히 사는 사람일수록, 매일 채워야 합니다"
- 톤 주의: 공포 소구 ❌ → "쓰는 만큼 채우는 게 관리다" 담백한 논리 ⭕

### SEC 04. 제품 등장
- 무드: 약병 ❌ → 협탁 위 유리잔 + 파우더, 물에 풀리는 장면의 이너케어 감성 컷
- 카피: **"밤의 루틴에, 마시는 한 잔을 더했습니다"**
- 기능성 문구 고정 노출: "정상적인 신경과 근육 기능 유지에 필요 / 에너지 이용에 필요"

### SEC 05. 나이트 루틴 제안 (숙면 축 — 페이지의 심장)
- 세로 타임라인: 22:00 스마트폰 내려놓기 → 22:10 **미지근한 물에 파우더를 타서 천천히 한 잔** → 22:20 가벼운 스트레칭 → 23:00 취침
- 카피: **"오늘 밤부터 따라 해보세요, 마그네슘 나이트 루틴"**
- 의도: 제품이 아니라 루틴을 파는 섹션. "타서 마시는 행위"가 차 리추얼처럼 보이게. SNS 재활용 소재.

### SEC 06. 데일리 리커버리 (리커버리 축)
- 장면: 아침 창가 스트레칭, 러닝 후 휴식 — "회복하는 장면"을 아름답게
- 카피: "운동한 날도, 야근한 날도. 몸을 많이 쓴 날일수록 밤의 한 잔이 다음 날을 만듭니다"
- 서브: "쉼도 실력입니다. 리커버리까지가 오늘의 운동"

### SEC 07. 차별점 ① 마시는 파우더 (제형 스토리)
- 카피: **"알약이 아니라, 마시는 파우더입니다"**
- 세로 스택 비교: 일반 알약형(삼켜야 함, 루틴이 '복용'이 됨) ↔ 파우더형(물에 타서 음료처럼, 목넘김 부담 없음, 밤의 리추얼로 자연스러움)
- 원료 형태(글리시네이트/구연산 등)와 흡수 근거는 확보 후 기입 [원료 확정 필요]
- 톤 주의: 알약 비하 ❌ → "매일 밤의 루틴에는 이 형태가 자연스럽다" ⭕

### SEC 08. 차별점 ② 함량 & 파우더 디테일
- 1회 분량당 마그네슘 함량 + 영양성분기준치 % / 부원료(실제 배합 기준, 인정 기능성 범위 내 서술)
- 파우더템의 구매 결정 디테일 3가지, 세로 스택: **맛**(은은한 [맛 확정 필요]) / **용해력**(미온수에 잘 녹는 입자 [실측 필요]) / **1회 분량**([스틱포/스푼 — 포장 형태 확정 필요])
- 카피: "매일 부담 없이, 그러나 하루치는 확실하게"

### SEC 09. 사회적 증거
- 리뷰 큐레이션: "저녁 한 잔이 루틴이 됐다", "떨어지면 불안해서 재구매" 류의 **습관·재구매 서사** 우선
- 재구매율·정기구독 수치가 있다면 최상단 배치
- 데이터 없을 시: 개발 스토리 + 체험단 루틴 후기

### SEC 10. 신뢰 · 안전성
- 인증 배지 세로 리스트: 건강기능식품 인증마크 / GMP / 중금속 검사 성적서 / 무첨가
- 카피: "비타민C처럼 매일 먹는 것이니까, 더 까다롭게 만들었습니다"

### SEC 11. 섭취 방법 & FAQ
- 방법: 저녁, 하루를 마무리할 때 물 한 컵에 1회 분량을 타서
- FAQ:
  1. 언제 마시는 게 가장 좋나요? → 밤 루틴 제안 (아침도 무방)
  2. 비타민C·유산균이랑 같이 먹어도 되나요? → **"기존 루틴에 그대로 더하세요"**
  3. 매일 마셔도 되나요? → 데일리 설계 + 과다 섭취 주의 의무 표기
  4. 맛은 어떤가요? 찬물에도 녹나요? → 파우더 디테일 재소환
  5. 임산부/신장질환자 → 전문가 상담 안내
- 주의사항 정직하게 표기 (신뢰 신호)

### SEC 12. 클로징 CTA
- 카피: **"내일의 컨디션은, 오늘 밤에 만들어집니다"**
- 옵션 세로 스택: 1개월 체험 / 3개월 루틴팩(추천) / 정기구독
- 구독 넛지: "루틴은 끊기지 않을 때 루틴이 됩니다"
- CTA 버튼: **"오늘 밤 루틴에 추가하기"**

## 5. 카피라이팅 원칙

1. **결핍의 언어 금지**: 부족, 결핍, 증상, 완화, 개선 → 챙기다, 채우다, 더하다, 관리하다, 루틴
2. **"한 알" 금지 → "한 잔"**: 파우더 제품이므로 섭취 단위는 항상 "한 잔"(또는 1회 분량)
3. 비타민C 앵커링은 본문에서만(SEC 02·10) — 오프닝 헤드라인에는 쓰지 않는다
4. 효능 단정 대신 장면: "숙면에 좋다" ❌ → 밤 루틴의 장면 묘사 ⭕
5. 느낌표 금지, 명령 대신 제안형("~해보세요")
6. 모바일 우선: 1스크린 1메시지, 카피 2줄 이내, 모든 요소 세로 1열

## 6. 디자인 톤앤매너

**v3부터는 자체 라인업(비타민B 컴플렉스 상세페이지) 톤을 그대로 따른다:**

| 요소 | 방향 (비타민B 상세 기준) |
|------|------|
| 배경 | 순백 화이트, 여백 넉넉하게 |
| 컬러 | 딥 네이비(헤드라인·밴드) + 베리 레드 포인트(오버라인·번호·CTA 버튼) |
| 타이포 | 센터 정렬, 2줄 이내 헤드라인, 영문 스몰캡 오버라인 |
| 사진 | 화이트 배경 플로팅 오브제 화보 (스틱·원료·유리볼), 페데스탈 연출 |
| 반복 모듈 | 스탯 3분할 행(헤어라인 구분) / 레드 원형 넘버링 ①② / 풀블리드 네이비 넘버 밴드 / 하단 스펙 표 / 네이비 고정 CTA 바 |
| 레이아웃 | 모바일 전용. 본문 콘텐츠는 세로 1열, 스탯·미니 아이콘류만 라인업 문법대로 3분할/2×2 허용 |
| 규격 | 상세이미지 가로 860px(플랫폼 표준), 내부 콘텐츠는 모바일 1열 기준으로 설계 |

**섹션 구조도 라인업 템플릿 문법으로 재편 (v3 와이어프레임 기준):**
히어로(평행 카피 "밤의 리커버리, 마그네슘이 챙깁니다" + 스탯 행) → 상태 공감("일찍 누웠는데도, 아침이 무겁다면") → 왜 부족한가(커피/스트레스/땀 + 통계) → 매일 채움의 근거 → 기능 넘버링 ①신경·근육 ②에너지(인정 문구 그대로, 숙면/리커버리 비주얼 축 배정) → 제품 등장 + 스펙 스탯 → 분말 스틱 제형 → "같은 마그네슘이 아닙니다" 2×2 → 네이비 사회적 증거 밴드(실데이터 없으면 섹션 제거) → 하루 1포 섭취법 → FAQ → 제품 정보 표 → 하단 고정 CTA("카트에 담기")

## 8. ⚠️ 표시·광고 심의 체크리스트 (필수)

건강기능식품 표시·광고는 자율심의(한국건강기능식품협회) 사전 심의 대상.

| 구분 | 금지 | 대안 |
|------|------|------|
| 질병 표현 | "불면증", "수면장애" 등 질병명 | 질병명 자체를 쓰지 않는다 |
| 기능성 초과 | "숙면 유도", "꿀잠", "회복 촉진", "근육통 완화" | 인정 문구 + 루틴/라이프스타일 묘사 |
| 단정/보장 | "2주면 달라집니다", "100% 체감" | 기간·확률 단정 전면 금지 |
| 비교 비방 | 특정사·특정 제품 비방 | 일반적 형태(알약 vs 파우더) 비교까지만 |
| 후기 | 효능 체감 후기 그대로 인용 | 심의 범위 내 표현의 후기만 선별 |

"리커버리"는 회복 효능으로 읽히게 쓰지 않고 라이프스타일 용어(리커버리 타임, 리커버리 루틴)로만 사용한다. 최종 문구는 심의 결과에 따라 조정.
