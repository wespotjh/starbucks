## 2. 컨셉 한 줄

**비타민C처럼 매일 챙기는 웰니스 기본템 미네랄.**
결핍·증상(쥐, 불면 등)을 파는 게 아니라 **루틴**을 판다.
두 키워드의 역할 — **숙면** = 하루를 잘 닫는 밤의 루틴, **리커버리** = 내일의 컨디션. "잘 자야, 회복된다"로 하나의 서사.

## 3. 디자인 톤 (비타민B 라인업 템플릿)

- 화이트 배경 · 딥 네이비 헤드라인 · 베리 레드 포인트(오버라인, ①② 번호, CTA 버튼)
- 센터 정렬, 헤드라인 2줄 이내, 화이트 배경 플로팅 오브제 화보 (히어로엔 포도 오브제 = 맛 모티프)
- 반복 모듈: 스탯 3분할 행 / 넘버링 기능 블록 / 네이비 사회적 증거 밴드 / 하단 스펙 표 / 네이비 고정 CTA 바
- 모바일 구매 100% 전제: 본문 콘텐츠는 세로 1열, 스탯·미니 아이콘류만 라인업 문법대로 가로 허용

### 5-1. 기능 설명 카피 (SEC 05 확정안)

인트로: "식약처가 인정한 마그네슘의 기능은 2가지입니다"

**① 정상적인 신경과 근육 기능 유지에 필요**
> 마그네슘은 신경 신호를 전달하고, 수축한 근육이 다시 이완되는 과정에 쓰입니다.
> 하루 종일 긴장했던 몸의 스위치를 끄는 밤 — 마그네슘이 필요한 시간입니다. *(→ 숙면 축)*

**② 에너지 이용에 필요**
> 몸이 에너지를 만들고 쓰는 과정 곳곳에 보조 인자로 참여하는 미네랄입니다.
> 자는 동안에도 몸은 에너지를 써서 회복합니다. 리커버리의 미네랄인 이유입니다. *(→ 리커버리 축)*

## 5. 카피 원칙

1. 결핍·증상·완화의 언어 금지 → 챙기다·채우다·루틴
2. 섭취 단위는 **"한포"** ("한 알"·"한 잔"·"마시는" 금지)
3. 효능 단정 금지 — 기능성은 인정 문구 그대로, 설명은 영양학 일반 정보 수준
4. 느낌표 금지, 제안형 어미("~해보세요")
5. 1스크린 1메시지, 카피 2줄 이내

## 6. 심의 체크포인트

- 질병명(불면증·수면장애) 사용 금지 / "숙면 유도"·"회복 촉진" 등 기능성 초과 표현 금지
- "숙면"·"리커버리"는 라이프스타일 용어로만 (루틴·세션·타임)
- 기간·확률 단정 금지, 후기는 심의 범위 내 표현만 선별
- 진행: 카피 확정 → 한국건강기능식품협회 자율심의 → 심의필 후 게시
