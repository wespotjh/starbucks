/* [근거] 하단 고정바 예약.
   경위 3단계를 그대로 남긴다 — 같은 함정을 다음 사람이 다시 밟지 않도록.
     시도 1: `.zg-detail{padding-bottom}` → `.zg-detail` 은 푸터를 포함하지 않아 무효 + 엉뚱한 여백.
     시도 2: `.footer{margin-bottom}`     → **스크롤 가능 영역은 자손의 보더박스로만 정해지고
                                          마지막 블록의 바깥 여백은 포함되지 않는다.**
                                          실측 scrollHeight 가 safe 0/34 양쪽 5364 로 동일했다. 무효.
     현재: **스크롤 컨테이너(body) 의 padding** 으로 확보한다. 이것만 scrollHeight 를 늘린다.
   ⚠ `.footer` 의 padding 은 `css/module/product/detail.css:4248`(≤1023px)에서
      `padding-bottom:100px important-플래그` 로 잠겨 있어 이길 수 없다(그 100px 은 그대로 쓴다).
   값은 **매직 상수 없이** 정한다:
     바 높이 = 82 + safe-area   (아래 바 규칙에서 82px 확정)
     예약    = 100(스킨) + P
     여유    = 100 + P - (82 + safe-area) = 18 + P - safe-area
   → `P = safe-area` 로 두면 여유가 **safe-area 와 무관하게 항상 18px** 이 된다.
     즉 노치 기기가 비노치 기기와 똑같은 여백을 갖는다.
     (`sa - 18px` 로 두면 여유가 정확히 0 이 되어 딱 붙는다 — 실측으로 확인했다)
   비노치(safe=0)에서는 env() 가 0 이라 **현재와 완전히 동일**하다. `max()`/`calc()` 도 필요 없다.
   새 important 0개. */

/* R-10 갤러리 4장을 같은 크기로 (운영 지시 2026-09-09)
   ⚠ 카페24는 **첫 슬라이드에만** `.thumbnail__item` 을 붙인다 (라이브 마크업 실측):
       <li class="thumbnail__item swiper-slide"><img src="{$big_img}"></li>   ← 대표이미지
       <li style="display:none" data-param="…"><img class="ThumbImage"></li>  ← 추가이미지 ×3
     그래서 `.thumbnail__item` 으로 건 규칙이 **1장에만 걸렸다.**
     실측(390px, 정사각 원본 1024²):
       1장(대표) 304×304  ← `max-width:78%` 가 걸려 작다
       2~4장     390×390  ← 우리 규칙이 안 걸려 스킨 기본값대로 꽉 찬다
     대표이미지만 작게 나오던 것이 이 때문이다.
   → 기준을 `.thumbnail__list > li` 로 옮겨 4장 모두 같은 규칙을 받게 한다.
     `78%` 상한을 없애고 슬라이드 폭을 꽉 채운다(운영 결정). 세로는 화면 비율로 잠근다.
   ⚠ `display` 는 여전히 선언하지 않는다. `object-fit: contain` 이라 어떤 비율이 와도

     `.zg-picked-head`(선택한 구성)와 **형제**라, 그것만 감추면 옵션이 상단에 남는다.
     실제 구조:
       .opt-content > .opt-content__payment > .fix-pc-l
         ├ .opt-content__pc   제목·가격·리뷰
         ├ .productOption     옵션 카드
         ├ .zg-picked-head    선택한 구성
         └ #totalProducts     선택 목록
     ⚠ `.opt-content` 도 쓸 수 없다 — 스킨이 두 곳에서 important 로 잠갔다
       (`.opt-content{display:block!important}` · `.mobile-layer:not(.fixed) .opt-content{...!important}`).
       이 파일은 새 important 를 쓰지 않는 것이 설계 규칙이라, 잠기지 않은
       **`.fix-pc-l`** 을 감춘다. 네 덩어리가 전부 그 안에 있다. */
  .zg-detail .mobile-layer:not(.on):not(.fixed) .fix-pc-l,
  .zg-detail .mobile-layer:not(.on):not(.fixed) .infoArea-footer {
    display: none;
  }
  /* 시트·하단바에서는 원래대로 되돌린다 */
  .zg-detail .mobile-layer.on .fix-pc-l,
  .zg-detail .mobile-layer.on .infoArea-footer,
  .zg-detail .mobile-layer.fixed .fix-pc-l,
  .zg-detail .mobile-layer.fixed .infoArea-footer {
    display: block;
  }
  /* 상단이 비므로 썸네일과 상세 사이 여백만 남긴다 */
  .zg-detail .mobile-layer:not(.on):not(.fixed) { margin: 0; padding: 0; }
