# 네이버페이 버튼 복원 — 카페24 적용 가이드 (전체 삭제 → 전체 붙여넣기)

파일 2개를 **통째로** 바꿉니다. 두 파일 다 라이브에서 받은 원본에 패치만 합친 완성본이라, 기존 내용은 그대로 들어 있습니다.

| 순서 | 카페24 파일 | 붙여넣을 파일 | 줄 수 |
|---|---|---|---|
| 1 | `ds/css/detail.css` | **`detail.css.txt`** | 1,532줄 |
| 2 | `ds/js/detail-ui.js` | **`detail-ui.js.txt`** | 1,323줄 |

스킨 HTML(`product/detail.html`)은 건드리지 않습니다. 네이버페이 버튼은 카페24 「네이버페이 구매」 앱이 페이지가 뜰 때 스스로 만들고, 우리는 그 버튼을 **숨기지 않고 자리만 잡아 주는** 코드만 넣습니다.

---

## 0. 편집창 여는 법

1. 카페24 관리자 로그인 → 왼쪽 메뉴 **디자인(PC/모바일)** → **디자인 보관함**
2. 현재 **대표 디자인**(사용 중 표시) 오른쪽의 **편집** 클릭 → 스마트디자인 편집창이 새 창으로 뜸
3. 편집창 **왼쪽 위 「파일 검색」** 칸에 파일 이름을 넣고 Enter
   - `detail.css` 를 치면 `ds/css/detail.css` 가 나옵니다 (다른 폴더의 detail.css 와 헷갈리지 않게 **경로가 `ds/css/`** 인지 확인)
   - `detail-ui.js` 를 치면 `ds/js/detail-ui.js`
4. 파일을 더블클릭하면 가운데에 코드 편집기가 열립니다.

> 저장 버튼은 편집기 위쪽 **「저장」**. 저장하면 바로 라이브에 반영됩니다(되돌리기는 아래 4번).

---

## 1. `ds/css/detail.css` — 전체 교체

1. `detail.css.txt` 를 메모장 등으로 열어 **Ctrl+A, Ctrl+C** (전체 복사)
2. 카페24 편집기에서 `ds/css/detail.css` 열기 → 편집기 안 클릭 → **Ctrl+A → Delete** (전부 지움)
3. **Ctrl+V** (붙여넣기)
4. 확인: 첫 줄이 `/* ====…` 이고 둘째 줄에 `ds/css/detail.css — 젠제네틱스 상품 상세 재스킨` 이 보이면 원본이 맞고,
   맨 끝(Ctrl+End)이 `…별도 분기가 없다 (실측 2026-10-23) */` 로 끝나면 패치가 들어간 것
5. **저장**

---

## 2. `ds/js/detail-ui.js` — 전체 교체

1. `detail-ui.js.txt` 를 열어 **Ctrl+A, Ctrl+C**
2. 카페24 편집기에서 `ds/js/detail-ui.js` 열기 → 편집기 안 클릭 → **Ctrl+A → Delete**
3. **Ctrl+V**
4. 확인: 둘째 줄에 `ds/js/detail-ui.js — 젠제네틱스 상품 상세 UI` 가 보이고, 맨 끝(Ctrl+End)이 `})();` 로 끝나면 됨
5. **저장**

---

## 3. 확인

1. 상품 페이지 열기: `https://zengenetics.co.kr/product/detail.html?product_no=11`
2. **Ctrl + Shift + R** (강력 새로고침 — 카페24 번들 캐시 때문에 한 번은 필요)
3. PC: 「장바구니 · 구매하기」 **바로 아래에 초록색 「N pay 구매」 한 줄**이 두 버튼과 같은 폭으로 보이면 성공
4. 모바일(또는 브라우저 창을 좁게): 하단 「구매하기」를 눌러 시트를 열면 **시트 안** 두 버튼 아래에 같은 버튼이 보입니다. 하단 고정바에는 안 뜨는 게 정상입니다.
5. 카카오페이 버튼은 계속 안 보이는 게 정상입니다 (요건 유지).

보이지 않을 때 순서대로:
- 시크릿 창에서 다시 열기 (브라우저 캐시)
- 편집창에서 두 파일이 정말 저장됐는지 (위 1·2의 확인 문구)
- 그래도 안 보이면 카페24 관리자 → **앱** → 「네이버페이 구매」 앱이 **사용 중**인지. 꺼져 있으면 버튼 자체가 생성되지 않습니다.

터미널에서 확인하려면 이 폴더의 `verify-live.sh` 를 실행하면 됩니다 (라이브 번들에 패치가 있는지 3가지를 검사).

### 24시간 뒤 재확인
카페24 쪽에서 파일이 되돌아가는 일이 있는지 보기 위해, 적용 **24시간 뒤**에 같은 확인을 한 번 더 합니다 (3번 그대로, 또는 `bash verify-live.sh`).
되돌아가 있으면 1·2번을 다시 하고, **어느 파일이** 돌아갔는지 알려 주세요.
