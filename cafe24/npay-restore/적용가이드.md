# 네이버페이 버튼 복원 — 카페24 적용 가이드 (복사·붙여넣기만 하면 됩니다)

작업 파일은 2개뿐이고, 둘 다 카페24 디자인 편집창에서 엽니다.

| 순서 | 파일 | 할 일 | 소요 |
|---|---|---|---|
| 1 | `ds/css/detail.css` | 맨 끝에 **블록 하나 붙여넣기** | 1분 |
| 2 | `ds/js/detail-ui.js` | **전체 지우고 새 파일로 통째 붙여넣기** | 1분 |
| 3 | 상품 페이지 | 새로고침해서 버튼 확인 | 1분 |

스킨 HTML(`product/detail.html`)은 건드리지 않습니다. 네이버페이 버튼은 카페24 「네이버페이 구매」 앱이 페이지가 뜰 때 스스로 만들고, 우리는 그 버튼을 **숨기지 않고 자리만 잡아 주는** 코드만 넣습니다.

---

## 0. 편집창 여는 법

1. 카페24 관리자 로그인 → 왼쪽 메뉴 **디자인(PC/모바일)** → **디자인 보관함**
2. 현재 **대표 디자인**(사용 중 표시) 오른쪽의 **편집** 클릭 → 스마트디자인 편집창이 새 창으로 뜸
3. 편집창 **왼쪽 위 「파일 검색」** 칸에 파일 이름을 넣고 Enter
   - `detail.css` 를 치면 `ds/css/detail.css` 가 나옵니다 (다른 폴더의 detail.css 와 헷갈리지 않게 **경로가 `ds/css/`** 인지 확인)
   - `detail-ui.js` 를 치면 `ds/js/detail-ui.js`
4. 파일을 더블클릭하면 가운데에 코드 편집기가 열립니다. 편집기 왼쪽에 **줄 번호**가 보입니다.

> 저장 버튼은 편집기 위쪽 **「저장」**. 저장하면 바로 라이브에 반영됩니다(되돌리기는 아래 5번).

---

## 1. `ds/css/detail.css` — 맨 끝에 붙여넣기

1. 편집기 안을 한 번 클릭한 뒤 **Ctrl + End** (맨 끝으로 이동)
2. **Enter** 를 한 번 눌러 빈 줄을 만듭니다
3. 이 폴더의 **`detail.css.append.css`** 파일을 열어 **전체 복사(Ctrl+A, Ctrl+C)** → 편집기에 **붙여넣기(Ctrl+V)**
4. **저장**

붙여넣은 블록은 `/* ==== R-12b 네이버페이 복원 — 2026-10-23` 로 시작하고,
마지막 줄은 `/* 구매 시트(.mobile-layer.fixed.on) 안의 장바구니·구매하기도 --zg-bar-h(54px) 라 별도 분기가 없다 (실측 2026-10-23) */` 입니다.
기존 내용은 한 글자도 지우지 않습니다.

## 2. `ds/js/detail-ui.js` — 전체 교체 (권장)

이 파일은 라이브에 올라가 있는 원본을 그대로 가져와서 **R-12 블록 한 곳만** 바꾼 것입니다. 통째로 바꾸는 게 가장 안전합니다.

1. `ds/js/detail-ui.js` 를 열고 편집기 안 클릭
2. **Ctrl + A** (전체 선택) → **Delete** (전부 지움)
3. 이 폴더의 **`detail-ui.js`** 파일을 열어 **전체 복사(Ctrl+A, Ctrl+C)** → 편집기에 **붙여넣기(Ctrl+V)**
4. 붙여넣은 뒤 확인 2가지
   - 첫 줄이 `/* ============================================================================` 이고 둘째 줄에 `ds/js/detail-ui.js — 젠제네틱스 상품 상세 UI` 가 보이는지
   - 마지막 줄 근처가 `})();` 로 끝나는지 (총 **1,323줄**)
5. **저장**

### 2-B. 블록만 바꾸고 싶을 때 (선택)

전체 교체가 불안하면 바뀐 부분만 바꿔도 됩니다. 현재 라이브 파일 기준:

- 지울 범위: **986줄 ~ 1045줄**
  - 986줄: `  /* ------------------------------------------- R-12 간편결제 앱 블록 차단`
  - 1045줄: `  }` ← `function watchAppPay() {` 가 끝나는 닫는 괄호
  - 1046줄은 빈 줄, 1047줄은 `  /* ------------------------------------------------- R-12 시트 바닥 실측` 입니다. **이 줄은 남깁니다.**
- 986줄 맨 앞에 커서를 두고 **Shift + 클릭**으로 1045줄 끝까지 선택 → Delete
- 이 폴더의 **`detail-ui.js.R-12.replace.js`** 를 전체 복사해 그 자리에 붙여넣기 → 저장

(2번과 2-B 중 **하나만** 하세요.)

## 3. 확인

1. 상품 페이지 열기: `https://zengenetics.co.kr/product/detail.html?product_no=11`
2. **Ctrl + Shift + R** (강력 새로고침 — 카페24 번들 캐시 때문에 한 번은 필요)
3. PC: 「장바구니 · 구매하기」 **바로 아래에 초록색 「N pay 구매」 한 줄**이 두 버튼과 같은 폭으로 보이면 성공
4. 모바일(또는 브라우저 창을 좁게): 하단 「구매하기」를 눌러 시트를 열면 **시트 안** 두 버튼 아래에 같은 버튼이 보입니다. 하단 고정바에는 안 뜨는 게 정상입니다.
5. 카카오페이 버튼은 계속 안 보이는 게 정상입니다 (요건 유지).

보이지 않을 때 순서대로:
- 시크릿 창에서 다시 열기 (브라우저 캐시)
- 편집창에서 두 파일이 정말 저장됐는지 (위 1·2의 확인 문구)
- 그래도 안 보이면 카페24 관리자 → **앱** → 「네이버페이 구매」 앱이 **사용 중**인지. 꺼져 있으면 버튼 자체가 생성되지 않습니다.

터미널에서 확인하려면 이 폴더의 `verify-live.sh` 를 실행하면 됩니다 (라이브 번들에 패치가 있는지 3가지를 검사).

## 4. 24시간 뒤 재확인 (되돌아가는지 감시)

카페24 쪽에서 파일이 되돌아가는 일이 있는지 보기 위해, 적용 **24시간 뒤**에 같은 확인을 한 번 더 합니다.
- 사람이 보는 법: 3번 그대로 (강력 새로고침 후 버튼 유무)
- 자동: `bash verify-live.sh` → `==> 패치가 라이브에 살아 있습니다.` 가 나오면 정상
- 되돌아가 있으면 1·2번을 다시 하고, **어느 파일이** 돌아갔는지 알려 주세요. (CSS 만 / JS 만 / 둘 다)
